# 版本与证据说明

本包为针对热历史与时空配准约束的GMAW缺陷事件识别而编写的研究参考实现。文档引用的MBGN论文是研究起点；本包没有附带原作者源代码、原始权重或用户工业原始数据，也不声称复现了论文结果。

`dataset_demo` 中全部信号、图像、轨迹和缺陷区间由程序合成。`results` 中的随包训练、基线、消融、延迟和配对比较结果均是合成流程验证，不能作为真实焊接性能、机理或统计显著性证据。程序没有执行现场焊接、热测量或在线控制。

正式数据运行应重新完成事件复核、时间空间校准、焊缝划分及验证参数冻结。请保留本包的验证记录，不用真实结果覆盖随包演示。

外部Python依赖遵循各自许可证；所引用研究论文的著作权属于相应权利人。包内未再分发这些论文全文。

`SHA256SUMS` 是交付文件的SHA-256清单，使用 `python scripts/verify_integrity.py` 核对。生成新实验结果不会改变旧文件的校验值；修改代码或配置后应记录新的版本。
