# 因果电信号延迟压力测试

## 测什么

在训练好的模型和验证集冻结阈值上，固定当前图像、当前工艺条件、当前目标位置、RT标签及评分单元，让电波形、原生功率均值、热状态和对应电弧位置历史整体来自早0、1、2、4个**原始图像帧索引**。8Hz等间隔记录分别对应0、125、250、500ms；输出始终报告实际时间差。

这是“当前时刻只能获得陈旧电传感器信息”的可控压力试验，保留其真实较早时间和位置。它不是把历史数据改成虚假的当前时间戳，不是时钟标定补偿，也不估计真实缺陷形成时滞。0帧条件是基准，其余条件不使用未来数据。

## 运行

```bash
python scripts/stress_causal_delay.py --data dataset_demo --checkpoint results/smoke_full/model.pt --output results/stress_delay --delays 0,1,2,4 --split test
python -m unittest tests.test_stress_delay -v
```

默认使用checkpoint同目录的 `threshold_selection.json`；必须明确来自validation且已核验split列。不会重训、重新选阈值或更改物理支持宽度。只接受本包原生因果输入模型的checkpoint；明确配置为中心窗或含未来电信号的配置会被拒绝。

## 如何保证公平与因果性

1. 早d帧按原始frame索引计算，而不是倒退d条已筛选监督记录。未知或其他缺陷排除不能改变物理时间差。
2. 每个条件均检查同一seam/segment、完整过去电信号支持、热状态warmup、连续帧间隔和当前目标的几何支持。热状态直接取已计算的较早全段状态，不重新用当前功率更新。
3. 用较早电弧位置重新计算针对**当前目标**的prior和mask。没有合法支持则排除，不扩大支持以强行保留条件。
4. 所有条件先取合法sample_id交集，再在完全相同的空间评分单元上预测和评价；图像、标签、检查区段均不改变。
5. 当前决策时间保持不变；电传感器信息年龄单列。指标中的报警延迟仍不含程序运行、通讯和执行器延迟。

如果没有共同支持，脚本保存 `common_coverage.json` 后停止。可基于这个几何诊断显式减少 `--delays` 最大值再运行，不能根据测试分数选择“最好看”的延迟，也不能临时放大支持范围。

## 输出

| 文件 | 内容 |
|---|---|
| predictions_delay_00/01/02/04.csv | 各条件预测、共同sample_id、原始标签、评分单元、信息年龄、实际电信号最早/最晚时间、支持token数 |
| metrics_delay_00/01/02/04.json | 相同冻结阈值下的帧/事件/覆盖指标及真实时间差 |
| stress_summary.csv | 便于比较的F1、AP、事件召回、误报每米、边界误差、首次命中延迟 |
| common_records.csv | 完全相同的当前样本与评分单元 |
| reference_events.csv | 未改变的参考事件 |
| common_coverage.json | 每种排除原因、共同ID摘要、实际评分覆盖和事件数 |
| stress_run_info.json | checkpoint/阈值文件哈希、数据指纹、冻结阈值来源及干预定义 |

应比较本次共同覆盖上的0帧基准与延迟条件，不能直接拿原先完整测试集的分数作分母。不同延迟的性能不保证单调下降；模型可能更多依赖当前图像，或原先对齐本身有误。合成数据结果只证明压力测试流程可执行，不能证明工业鲁棒性。所有延迟条件均共享一个已冻结checkpoint，因此也不是各自重新训练后的能力上限。
